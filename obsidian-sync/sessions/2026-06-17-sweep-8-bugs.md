# Program-wide sweep: 8 same-class bugs fixed + deployed

After fixing two reported production bugs (dead-end "Done" button; `core8Done` requiring a W-2-only field), the user asked to hunt the same error classes across the whole tool. A 2-phase adversarial sweep + empirical reproduction across every income type surfaced **8 same-class issues**; all fixed, Chrome-verified, gated, and deployed.

## Done
- **Fix 1 (leak):** raw `${bracketBlock(...)}` template source leaked into 7 nodes' detail panels — extraction captured the source, not its output. Expand at build (`tools/build-v2.mjs` `bracketBlock` + `expandDetails`). Side benefit: revives the chart's dead tax-bracket selector (there was no `.bracket-block` to filter before).
- **Fix 2 (cross-namespace chart):** the personal chart rendered only one income namespace, hiding plan actions assigned canonical cross-namespace nodeKeys (a contractor's plan pulls in shared `w2:` steps, often tier-1) and false-flagging primary-track equivalents "Skipped." Now renders primary track in full + every other track the plan touches as an active-only addendum (`flowchartHTML` gains `activeOnly`; `personalChartView` union render, `src/ui/app.mjs`). Verified contractor 11/11 & business 8/8 nodeKeys visible.
- **Fix 3 (completion trap):** ticking an effect-bearing action (e.g. capture match → `matchCaptured:'yes'`) dropped it from the recomputed plan with no card to untick. Re-surface closed actions in a "Completed" ledger with a working uncheck (`planPanel`).
- **Fix 4 (duplicate ids/data-fk):** tier-1 actions render twice; checkbox `data-fk` + detail-toggle id/`data-fk` now distinct per copy (`actionCard`/`detailToggle`).
- **Fix 5 (calc debounce TypeError):** the initial-paint nudge dispatched input events through an 80ms debounce, leaving timers that fired after a fast tab-switch wiped `#app` → `getElementById(...).innerHTML` on null. Replaced with a synchronous, guarded initial compute (`tools/extract-calc-live.mjs`, regenerated `src/ui/calculators-live.mjs`). 0 pending timers, 0 errors on nav-away.
- **Fix 6/7/8 (minor):** dead "Back" on diagnostic section 1 → omit + spacer; non-clickable "+" on skipped chart nodes → omit; empty `incomeType` pill for unmapped values → guard.
- **Verification:** every fix reproduced then confirmed in headless Chrome; full-chart + W-2 + welcome→diagnostic regression-checked. **10/10 v2 gates green** (incl. 245-vector calculator parity in real Chrome).
- **Ship:** committed `a3b8453` on `v2`; deployed `a5e5655` on `main` (`flowchart.html` cutover, 964,766 bytes) + pushed to `origin/main`.
